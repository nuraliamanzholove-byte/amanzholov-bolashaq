# Amanzholov / Болашақ

Учебный навигатор для абитуриентов Высшего колледжа ВКУ имени С. Аманжолова.

## Страницы
- `/` — главная;
- `/about` — о колледже и проекте;
- `/programs` — поиск, фильтрация, избранное, сравнение специальностей;
- `/test` — 21 вопрос, 7 шкал интересов, объяснение и скачивание результата;
- `/admission` — чек-лист и ответы о поступлении;
- `/contacts` — контакты и официальные источники.

## Запуск
Node.js 22.13+; `npm install`, затем `npm run dev`. В управляемой среде используется предусмотренный helper install-dependencies.mjs.

Технологии: React, TypeScript, Vinext / Vite, CSS; размещение в Cloudflare Workers через Sites.

## Профориентация
Плавающий **Bolashaq AI** — отдельный настоящий LLM-чат: серверный Google Gemini API (бесплатный тариф с квотами), русский/казахский язык, контекст переписки и справка колледжа. Для работы нужен собственный `GEMINI_API_KEY` в `.dev.vars` или секретах хостинга. Пошаговая инструкция: [AI_SETUP.txt](AI_SETUP.txt). Ключ в архив не включён. Ответы живой модели без ключа не проверялись.

Проверки: `npm run test:chat`, `npm run typecheck`, `npm run build`. Тесты используют тестовую подмену HTTP только в тестовом процессе; production-код всегда обращается к Google Gemini.

## Профориентационный тест
Прозрачная учебная экспертная система, не внешняя LLM. 21 утверждение: 3 на каждую из 7 шкал; ответы 0–4. Результат = сумма / 12 × 100. При равенстве баллов порядок шкал условный. Это не валидированный психологический тест; баллы не означают вероятность поступления, успеха или профессиональную пригодность. Персональные сведения не запрашиваются. Прогресс, избранное и чек-лист используют localStorage.

Источники проверены 10.11.2026 и перечислены на странице контактов. Расхождения между общим каталогом и страницей приёма отмечены в карточках. Шаблонный телефон с официальной страницы не воспроизводится. Пейзаж создан для оформления, не является фотографией территории колледжа.
