AMANZHOLOV / БОЛАШАҚ — САЙТ ДЛЯ АБИТУРИЕНТОВ

В архиве исходники готового сайта, стили и изображение долины.
Также добавлен Bolashaq AI — настоящий ИИ-чат в правом нижнем углу.
Эта версия использует Google Gemini с бесплатным тарифом и квотами.
Нужен ключ Google AI Studio, а не OpenAI: инструкция AI_SETUP.txt.
Без ключа сайт запускается, но чат сообщает, что ИИ ещё не подключён.
Это React/TypeScript-проект, поэтому двойной щелчок по HTML не используется.

ЗАПУСК НА КОМПЬЮТЕРЕ
1. Полностью распакуйте архив.
2. Установите Node.js версии 22.13 или новее, если он ещё не установлен.
3. Откройте папку Amanzholov_Bolashaq в VS Code.
4. Откройте Терминал → Создать терминал. В Windows удобно выбрать Command Prompt (cmd).
5. Выполните:
   npm ci
   npm run dev
6. Откройте в браузере http://localhost:5173
   Если терминал покажет другой адрес, используйте его.
7. Пока вы пользуетесь сайтом, терминал должен оставаться открытым.
   Остановка: Ctrl+C.

Для установки зависимостей нужен интернет. node_modules не включена в ZIP:
она создаётся командой npm ci.
