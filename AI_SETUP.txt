AMANZHOLOV / БОЛАШАҚ — ИИ-ЧАТ С GOOGLE GEMINI

ЭТА ВЕРСИЯ ИСПОЛЬЗУЕТ GOOGLE GEMINI, А НЕ OPENAI.
Модель по умолчанию: gemini-2.5-flash-lite.
Для неё Google указывает бесплатные входные/выходные токены на Free Tier.
Бесплатный тариф имеет квоты. Доступ и лимиты зависят от аккаунта/проекта;
гарантировать бесплатную работу для любого аккаунта или бесконечные запросы нельзя.
Не подключайте платёжный аккаунт, если хотите использовать только Free Tier.
При исчерпании квоты чат покажет ошибку и предложит повторить позже.
В платном проекте запросы могут тарифицироваться по условиям Google.
Google может использовать запросы бесплатного тарифа для улучшения продуктов.
Не отправляйте персональные данные. Условия использования и возрастные требования
нужно проверить в Google AI Studio; для школьного/учебного аккаунта возможны
ограничения администратора. Казахстан включён в список доступных регионов.

ЗАПУСК НА WINDOWS ЧЕРЕЗ CMD
1. Распакуйте этот архив в НОВУЮ папку, чтобы не перепутать со старой версией.
2. Откройте папку Amanzholov_Bolashaq, где расположен package.json, в CMD.
3. Выполните:
   npm.cmd ci
4. Откройте https://aistudio.google.com/apikey
   Войдите в свой Google-аккаунт и создайте ключ Gemini API (Create API key).
   Убедитесь, что выбран бесплатный проект/тариф Free Tier.
   Если сервис просит оплату или недоступен — не оплачивайте автоматически;
   сначала проверьте доступ, проект и квоты в AI Studio.
5. В CMD выполните:
   copy .dev.vars.example .dev.vars
6. Откройте .dev.vars в редакторе. Оставьте две строки и вставьте свой ключ:
   GEMINI_API_KEY="сюда_ваш_ключ_Google_AI_Studio"
   GEMINI_MODEL="gemini-2.5-flash-lite"
   Файл должен называться .dev.vars, без .txt, рядом с package.json.
   Старые OPENAI_API_KEY и OPENAI_MODEL здесь не используются.
7. Сохраните файл и выполните:
   npm.cmd run dev
8. Откройте адрес из терминала (обычно http://localhost:5173).
9. Нажмите кнопку Bolashaq AI справа внизу и задайте вопрос.
   Терминал должен оставаться открытым. Остановка: Ctrl+C.
   После изменения ключа остановите и заново запустите сервер.

ПРОВЕРКА ДИАЛОГА
Спросите: «Я заканчиваю 9 класс, люблю информатику и объяснять другим.
Сравни два подходящих направления». Потом: «А какое из этих двух больше
связано с программированием?» Затем: «Енді қазақша қысқаша түсіндір».
Это настоящий запрос к модели. Шаблонных ответов на вопросы нет.
Текст приветствия, кнопки и сообщения об ошибках являются интерфейсом.

ОШИБКИ
NOT_CONFIGURED — сервер не видит GEMINI_API_KEY. Проверьте файл и перезапуск.
INVALID_API_KEY — ключ Gemini неверный/истёк; ключ OpenAI не подходит.
ACCESS_DENIED — проверьте права ключа и доступ проекта к Gemini API.
API_DISABLED — включите Generative Language API для проекта ключа.
FREE_LIMIT_REACHED — исчерпана квота Gemini. Проверьте лимит в AI Studio,
подождите его восстановления. Повторная генерация ключа не увеличивает квоту проекта.
MODEL_UNAVAILABLE — модель недоступна аккаунту/проекту или снята с поддержки.
REGION_UNAVAILABLE — API недоступен для региона аккаунта или сервера.
При ошибке можно посмотреть Network → POST chat → Response; ключ там не выводится.

БЕЗОПАСНОСТЬ И ДАННЫЕ
Ключ хранится только на сервере, не вставляйте его в браузерный JavaScript.
Не присылайте его в переписку, не включайте .dev.vars в общий архив.
Разговор хранится в sessionStorage вкладки, максимум 12 пар сообщений с
ограничением длины. Для ответа история передаётся Google. Кнопка «+» очищает чат.
Факты о колледже взяты из исходного учебного сайта (дата справки 10.11.2026).
Свежие цены, сроки, гранты и наличие мест нужно сверять с приёмной комиссией.
Веб-поиск и подача заявлений не подключены.

ПРОВЕРКИ
npm.cmd run test:chat
npm.cmd run typecheck
npm.cmd run build
Проверены серверные сценарии с тестовыми HTTP-ответами и сборка.
Живой ответ Gemini без ключа владельца не проверялся.

ПУБЛИКАЦИЯ
Нужен серверный Cloudflare Worker, совместимый с проектом; статический
GitHub Pages не запустит /api/chat. Сборка: npm.cmd run build.
В хостинге отдельно задаются GEMINI_API_KEY и GEMINI_MODEL.
Нужны глобальные ограничения запросов/WAF для публичного доступа;
в коде есть только базовый лимит на пользователя/IP в пределах одного Worker.
Бесплатные квоты Google общие для проекта и не снимаются этим лимитом.
